# Exploit Shield Marketing Website

Marketing site for **Exploit Strike** focused on the **Exploit Shield** external threat intelligence product.

## Stack

- Vite
- React + TypeScript
- React Router
- CSS design tokens (Black Kite–inspired dark SaaS styling)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Routes

- `/` — Home (Exploit Shield threat intel)
- `/platform` — Product deep dive
- `/solutions` — Solutions overview
- `/solutions/external-threat-intelligence`
- `/solutions/third-party-exposure`
- `/case-studies`
- `/about`
- `/book-a-demo`
- `/privacy`, `/terms`

## Notes

- Demo form validates client-side and opens a `mailto:` draft to `info@exploitstrike.com`.
- Product claims are based on publicly described Exploit Strike / Exploit Shield capabilities.
